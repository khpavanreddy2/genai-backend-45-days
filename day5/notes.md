
# Day 5 – Python Collections

## Topics Covered
1. Lists
2. Tuples
3. Sets
4. Dictionaries
5. Nested and mixed data structures

## 1. Lists
- Ordered and mutable.
- Allow duplicate values.
- Access using indexing and slicing.
- Methods: append(), extend(), insert(), remove(), pop(), sort(), reverse(), copy(), clear(), index(), count().

## 2. Tuples
- Ordered and immutable.
- Allow duplicate values.
- Access using indexing and slicing.
- Methods: count(), index().
- Tuple packing and unpacking.
- Convert between lists and tuples.

## 3. Sets
- Store unique elements.
- Mutable, but do not support indexing.
- Create an empty set using set().
- Methods: add(), update(), remove(), discard(), pop(), clear().
- Operations:
  - Union: |
  - Intersection: &
  - Difference: -
  - Symmetric difference: ^

## 4. Dictionaries
- Store key-value pairs.
- Keys are unique; values can repeat.
- Dictionaries preserve insertion order.
- Access using dict[key] or dict.get(key).
- Methods: keys(), values(), items(), update(), pop(), popitem(), copy(), clear().

## 5. Nested and Mixed Data Structures
- Lists containing dictionaries.
- Dictionaries containing lists and sets.
- Nested dictionaries.
- Iterating through nested structures.
- Calculating totals and averages from stored data.

## Important Concepts
- append() adds one object; extend() adds individual elements.
- Tuples are immutable.
- Sets contain unique values and have no indexing.
- remove() removes by value; pop() removes by index in lists.
- b = a creates another reference; a.copy() creates a shallow copy.
- dict[key] raises KeyError for a missing key; dict.get() returns a default.
