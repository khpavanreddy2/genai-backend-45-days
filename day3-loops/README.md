# Day 03 – Python Loops and Number Logic

This folder contains the practice work and revision material from Day 3 of my 45-day Generative AI Engineering learning journey.

## Topics covered

- `for` loops and `range()`
- `while` loops and loop conditions
- `break`, `continue`, and `pass`
- Nested loops and star patterns
- Accumulator variables
- Number-processing logic using `% 10` and `// 10`
- Factorial, digit sum, digit count, reverse, palindrome, and Armstrong number
- Largest/smallest digit and even/odd digit counts
- Number guessing game

## Files

| File | Description |
|---|---|
| `loops_practice.py` | Basic loops, ranges, control statements, nested loops, and patterns |
| `number_problems.py` | Number-based problems using loops |
| `guessing_game.py` | A simple number guessing game |
| `git_github_revision.md` | Git and GitHub commands reviewed during the course |
| `Day_3_Python_Loops_and_Git_GitHub_Complete_Notes.pdf` | Complete Day 3 revision notes |

## How to run

Run a Python file from this folder:

```bash
python loops_practice.py
python number_problems.py
python guessing_game.py
```

These are learning exercises. Some examples use fixed values; input-based examples ask for user input.
